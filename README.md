# 高さの図鑑 / Japan Height Atlas

日本の高層ビルや塔、橋などを立体イメージとともに紹介する図鑑です。左右の矢印またはスワイプで切り替えられます。

順位は公開資料で確認できた範囲の暫定値です。施設の一群を1件にまとめる場合があり、全国の全建造物を網羅した順位ではありません。建築物、橋、塔などの高さには測定基準の差があります。多くのビルは共通形状を使用した模式モデルで、実物の細部や形を忠実に再現したものではありません。詳しくはサイトの「この図鑑について」と各施設の出典リンクを参照してください。

`index.html` をルートとする静的サイトです。3D表示には同梱の Three.js を使用しています（MIT License、`vendor/THREE-LICENSE.txt`）。WebGLが使えない環境では立体イメージに切り替わります。
